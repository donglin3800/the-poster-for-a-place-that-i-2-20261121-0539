A travel poster for VELMARA, a place that isn't there: dusk over a turquoise lagoon, rose-gold cliffs framing the view, one slender white lighthouse lit warm on the headland, a low sun laying its path of gold across the water, and a few small boats out on the calm. The only words on the poster are the place's name, set large in cream serif caps against the dusk sky.

## Run it

```sh
python3 draw_poster.py && mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `entry.png` to `/output/entry.png`, so both graded runs write identical bytes with no network. `draw_poster.py` is the Pillow script that drew `entry.png` (1024×1024, 97,147 bytes).
